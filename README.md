# Data_Exploration

Projekat je rađen na master studijama iz predmeta Tehnike i metode analize podataka u saradnji sa firmom Nissatech. Zadatak projekta bila je primena metoda za istraživanje vremenskih serija nad "environmental parameters" podacima. Odrađena je inicijalna analiza podataka, nakon čega je obavljeno preprocesiranje podataka, a zatim i provera stacionarnosti signala. Nakon toga je urađeno modelovanje signala ARIMA metodom.
